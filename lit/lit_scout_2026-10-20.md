## Verdicts
A. Forward-Forward
- Moved only on the ANN side (HCL-FF 91.68 / 70.09 on CIFAR-10/100, CVPR 2026, via within-layer gradients + batch contrastive loss); spiking FF is still stuck at FFGAF's 75.64 CIFAR-10 with frozen spikes, and nothing found is two-neuron-local.
- Most important: Wu et al., "The Price of Locality" (NeurIPS 2026, arXiv 2609.33240): proves the FF-vs-BP depth gap is structural (inter-layer drift floor + rank-one kernel collapse), backed empirically by Chen's audit showing FF has no memory edge over fair BP at ImageNet-100 scale.
- Empty: no spiking FF on any neuromorphic chip; the only FF-on-hardware result is Renaudineau's memristor array (89.5% vs BP 90.0%, 4-class, single layer in-situ, non-spiking).

B. On-chip learning
- Barely moved: the only new chip-learning demos are LANL's fully on-chip tabular Q-learning on Loihi 2 (36% agents solve vs CPU 62%, 0.02 W) and an FPGA SOLSA trainer (MNIST 95.92% on-chip, error still backpropagated spatially); no demo learns hidden layers with a two-neuron-local rule above MNIST difficulty.
- Most important: still Hajizada CLP-SNN/CLANE on Loihi 2 (arXiv 2511.01553 v2 / 2605.28387): three-factor prototype rule, 90.0% 25-shot OpenLORIS, 0.05 mJ, but the feature extractor stays on a host GPU and the third factor is host-routed, so it is partial-local.
- Empty: Hala Point (no learning result), Speck/Xylo and Innatera (inference-only), Akida 2 (no paper; AKD1000 last-layer STDP 63-77% on 3 keywords is the ceiling), e-prop on SpiNNaker2 (only an 8x-energy-vs-V100 line in the chip paper, no accuracy).
